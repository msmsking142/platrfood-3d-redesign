# Rider verification and launch mode

- **Rider KYC:** `riders.licenceFile` and `riders.selfieFile` hold private storage filenames under `rider-kyc/<userId>/...`. Upload through `rider/document_upload_POST` and `helpers/uploadRiderDocument`. `rider/action_POST` → `submit_documents` sets status to `pending` and records `documentsSubmittedAt`. `helpers/riderKycUrls` supplies 900-second signed URLs to `rider/dashboard_GET` and `admin/overview_GET`. Admin approval requires both files; rejection stores `reviewNote`. Only approved riders can go online or accept orders.
- **Rider UI:** `components/RiderDashboard` supports `?section=overview|orders|history|earnings|verification|profile|help`. `RiderVerification` hosts the Hindi training video using `HindiOnboardingVideo`, `scenes=riderAcademyScenes`, `renderScreen=RiderAcademyScreens`, and watched-key suffix `rider`.
- **Rider onboarding fee:** One-time, non-refundable ₹199 (`app_settings.rider_onboarding_fee`) plus GST at `commissionGstBps` (₹234.82 total), paid through Razorpay. Store amounts in **PAISE** in `rider_onboarding_payments`. Add `rider/onboarding_fee_order_POST` and `rider/onboarding_fee_verify_POST`; `riderOnboardingFee.recordPaid` must be idempotent and set `riders.onboarding_fee_paid_at`. Handle webhook purpose `"zipto_rider_onboarding"` directly in `processRazorpayWebhookEvent`, not through `paymentReconciliation`. Require `onboardingFeePaidAt` for `submit_documents`. Gate document uploads behind a payment card in `RiderVerification` and show the fee in `RiderOnboarding`. Merchants have no joining fee; show Basic ₹0 and Pro ₹2,499 + GST in the `MerchantOnboarding` plan step.
- **Launch mode:** `app_settings.launch_mode` defaults to `true`. `_index` shows “Launching soon” to non-admins, and `customer/place_order_POST` blocks their orders. Admins toggle it with `set_launch_mode`.
- **Site paused:** separate `app_settings.site_paused` (admin action `set_site_paused`, returned by settings_GET). When true, AppShell shows `SitePausedScreen` to all non-admins (customers, restaurants, riders) except /login and /terms; login page hides Create account; register endpoint returns 403.
